# EduTest — Оролт/Гаралтын тестийн систем

Их дээд сургуулийн багш нарт зориулсан Pre/Post (оролт/гаралт) тестийн систем.
Багш тест үүсгэж QR холбоосоор тараана, оюутан **бүртгэлгүйгээр** бөглөнө,
систем нь оюутан тус бүрийн оролт/гаралтын ахицыг автоматаар тааруулж
харьцуулна.

Пилот хичээл: **Эмийн хими 1 (PHR201)**. Интерфэйс бүхэлдээ монгол хэл дээр.

---

## Технологийн стек

| Давхарга | Технологи |
|---|---|
| Backend | Python 3.10+ · Flask 3 |
| Өгөгдлийн сан | SQLite (стандарт сангийн `sqlite3`) |
| Frontend | Jinja2 · CSS (design token) · энгийн JavaScript |
| График | Chart.js (локалаар `static/vendor/`-т) |
| Экспорт | `csv` (стандарт сан) · openpyxl · python-docx |
| Тайлангийн график | matplotlib (заавал бус) |
| QR | `qrcode` (цэвэр Python, SVG гаралт) |
| Тест | `unittest` (стандарт сан) |

**Supabase ашигладаггүй.** Мөн Firebase, PostgreSQL, Node.js, npm, React,
Vite, Docker аль нь ч ашиглаагүй. Нэвтрэлт нь Flask session дээр, өгөгдөл нь
локал SQLite файлд байна. Гадаад API руу ямар ч дуудлага явуулдаггүй —
систем интернетгүй танхимд бүрэн ажиллана.

### Хуучин хувилбарын өгөгдлийн сан

Хуучин `edutest.db`-тэй шууд ажиллуулж болно. Програм эхлэхэд схемийн
шинэчлэл **автоматаар** хийгдэж, консол дээр хийсэн алхмаа хэвлэнэ:

```
Өгөгдлийн сангийн шинэчлэл хийгдлээ:
  • questions.qtype нэмэв
  • questions.match_a нэмэв
  ...
```

Шинэчлэл нь мөр устгахгүй, зөвхөн багана нэмнэ. Одоо байгаа асуулт бүр
`qtype='single'` болж, урьдын зан төлөв яг хэвээр үлдэнэ. Дахин
ажиллуулахад аюулгүй (idempotent).

### Өгөгдлийн санг дахин үүсгэх

`--reset` нь одоо байгаа бүх өгөгдлийг устгана — болгоомжтой хэрэглэнэ үү.

## Асуултын төрлүүд

Гурван төрөл дэмжигдэнэ. Бүгд A/B/C/D дөрвөн сонголттой.

| Төрөл | Оюутанд | Оноо өгөх дүрэм |
|---|---|---|
| **Нэг сонголттой** | Radio товч | Зөв хариулт сонгосон бол бүтэн балл |
| **Олон сонголттой** | Checkbox | **Бүх** зөв хариултыг яг таг сонгосон бол бүтэн балл |
| **Харгалзуулах** | Зүүн зүйл бүрт дугаар сонгоно | **Бүх** хос зөв бол бүтэн балл |

**Хэсэгчилсэн оноо байхгүй.** Гурван зүйлээс хоёрыг зөв сонгосон бол 0 балл.
Ингэснээр Оролт/Гаралтын хувь тодорхой, харьцуулахад шударга байна.

### Харгалзуулах асуулт хэрхэн ажилладаг вэ

Багш зүүн талд A, B, C, D зүйлсийг, баруун талд тэдгээрийн зөв хосыг бичнэ:

```
A  Ус      ↔  H2O
B  Төмөр   ↔  Fe
C  Алт     ↔  Au
D  Мөнгө   ↔  Ag
```

Оюутанд харуулахдаа баруун талыг **автоматаар холино** — эс бөгөөс зөв
хариулт A→1, B→2 гэж эгнэчихнэ. Холилт нь асуултын дугаараас гардаг
тогтмол сэлгэлт тул хуудсыг дахин ачаалахад өөрчлөгдөхгүй, оюутан бүрт
ижил байна.

Зөв хариултыг өгөгдлийн санд `A>2,B>1,C>4,D>3` хэлбэрээр хадгална
(зүүн үсэг → дэлгэц дээрх мөрийн дугаар).

## Оролт/Гаралт тааруулах дүрэм

Энэ нь системийн хамгийн чухал логик тул тодорхой бичив.

**Тааруулах түлхүүр:**

```
ангийн бүлэг (class_group_id) + хэвийн болгосон оюутны код (normalized_student_code)
```

Тааруулалт нь **зөвхөн нэг тестийн хосын дотор** (`test_pair_id`) явагдана —
өөр хосын оролдлого хоорондоо холилдохгүй.

**Имэйл тааруулалтад ОГТ оролцохгүй.** Оюутан оролт, гаралт дээр өөр өөр
имэйл бичсэн ч, огт бичээгүй ч тааруулалт зөв ажиллана. Имэйл нь зөвхөн
харуулах, заавал бус талбар.

**Кодыг хэвийн болгох:** эхэн/төгсгөлийн зай таслах → дотоод зайг бүгдийг
арилгах → том үсэг болгох.
Жишээ: `  b23 0101 ` → `B230101`

**Нэрийн зөрчил:** ижил бүлэг, ижил кодоор өөр нэр бичигдвэл систем
**чимээгүй нэгтгэхгүй**. Хоёр нэрийг хоёуланг нь хадгалж, багшид
«Нэр зөрчилтэй» тэмдгээр харуулна. Багш өөрөө шалгаж залруулна.

## Экспорт

Шинжилгээ болон Экспорт хуудаснаас гурван форматаар татна:

### CSV
UTF-8 BOM-той (`utf-8-sig`) тул Excel дээр монгол үсэг зөв нээгдэнэ.

### Excel (`.xlsx`)
Гурван хуудастай:

| Хуудас | Агуулга |
|---|---|
| `Summary` | Нэгтгэсэн үзүүлэлт, дундаж, ахисан оюутны хувь |
| `Student Results` | Тааруулсан оюутан бүрийн Оролт/Гаралт/Өөрчлөлт |
| `Unmatched Attempts` | Зөвхөн нэг тест өгсөн оролдлогууд |

Толгойн форматлалт, баганын автомат өргөн, эхний мөр царцаах
(freeze panes), шүүлтүүр, ахицын өнгөт ялгаа (ногоон/саарал/улаан) орсон.

### Word (`.docx`)
Сургуулийн нэр, хичээл, бүлэг, тестийн хос, тайлангийн огноо, нийт
оролцогч, Оролт/Гаралтын дундаж, дундаж ахиц, таарсан/таараагүй тоо,
**автоматаар үүсгэсэн ерөнхий дүгнэлт**, **4 график** болон бүрэн
харьцуулалтын хүснэгт.

Графикууд нь Шинжилгээ хуудасны график ижил өгөгдөл, ижил өнгөтэй:

1. Оролт ба Гаралтын дундаж
2. Ахицын ангилал (ахисан / өөрчлөлтгүй / буурсан)
3. Онооны тархалт
4. Оюутан тус бүрийн Оролт/Гаралт (эхний 30 оюутан)

Графикийг matplotlib сервер талд зурж PNG болгон шигтгэнэ. **matplotlib
суулгаагүй бол тайлан графикгүйгээр бүрэн үүснэ** — бусад бүх агуулга хэвээр.

## Аюулгүй байдал

Хэрэгжүүлсэн зүйлс:

- **Нууц үг** — PBKDF2-HMAC-SHA256, 240,000 давталт, санамсаргүй давс.
  Ил задгай нууц үг хэзээ ч хадгалагдахгүй.
- **SQL injection** — бүх query параметрчлэгдсэн (string concat байхгүй).
- **CSRF** — POST бүр дээр session-д суурилсан token, `hmac.compare_digest`.
- **XSS** — Jinja2 autoescape идэвхтэй, `|safe` хаана ч ашиглаагүй.
- **Эрхийн хяналт** — `@login_required`, `@admin_required`, `owned_course()`,
  `owned_test()`. Багш зөвхөн өөрийн хичээлд, админ бүгдэд ханддаг.
- **Оюутны нийтийн хуудас** — зөвхөн `open` төлөвтэй тест харагдана.
  Ноорог, хаагдсан тест 403 буцаана.
- **Зөв хариулт нууцлагдсан** — оюутны үр дүнгийн хуудас нь зөв хариултын
  түлхүүрийг ил гаргахгүй (зөвхөн өөрийн хариулт зөв/буруу эсэх).
- **Session cookie** — `HttpOnly`, `SameSite=Lax`.
- **Татах файлын толгой** — `X-Content-Type-Options: nosniff`,
  `Cache-Control: no-store`, RFC 6266-ийн дагуу нэр.
- **Оролтын шалгалт** — бүх форм сервер талдаа шалгагдана (браузерын
  `required` дээр найдахгүй).

## Байршуулах тэмдэглэл

`app.py` доторх сервер нь **Flask-ийн хөгжүүлэлтийн сервер** — production-д
ашиглахгүй. Бодит хэрэглээнд WSGI сервер ашиглана:

```bash
python3 -m pip install waitress
python3 -c "from waitress import serve; import app; serve(app.app, host='0.0.0.0', port=8000)"
```

эсвэл gunicorn (macOS/Linux):

```bash
python3 -m pip install gunicorn
EDUTEST_SECRET=... EDUTEST_ENV=production gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

**Chart.js CDN-ээс биш локалаас ачаалагдана** (`static/vendor/`). Тиймээс
шинжилгээний график интернетгүй танхимд ч ажиллана. Icon-ууд нь inline SVG
sprite тул icon font, гадаад дүрсийн сан огт шаардахгүй.

**QR код нь сервер ажиллаж буй хаягаар үүснэ.** `localhost` дээр нээсэн бол
QR зөвхөн тухайн компьютер дээр ажиллана. Утаснаас турших бол:

```bash
HOST=0.0.0.0 python3 app.py
# дараа нь http://<таны-IP>:5000 хаягаар нээнэ
```

## Мэдэгдэж буй хязгаарлалтууд

1. **Асуултын төрөл** — нэг сонголттой, олон сонголттой, харгалзуулах
   гурав дэмжигдэнэ. Бичвэр хариулт, зураг оруулах, дараалал эрэмбэлэх
   төрөл хараахан байхгүй. Сонголтын тоо дөрвөөр тогтмол (A/B/C/D).
   Харгалзуулах болон олон сонголттой асуултад хэсэгчилсэн оноо байхгүй.
2. **Тестийн хугацаа** — цаг хэмжигч (таймер) хэрэгжээгүй. Багш тестийг
   гараар «Хаах» товчоор зогсооно.
3. **Word тайлангийн график** — оюутан 30-аас олон бол сүүлийн графикт
   эхний 30 нь л харагдана (уншигдахуйц байлгах үүднээс). Бүрэн жагсаалт
   хүснэгтэд байна. Excel файлд график ороогүй.
4. **Хуудаслалт (pagination)** — тестийн жагсаалтын хайлт/шүүлтүүр клиент
   талд ажиллана. Хэдэн зуун тест болвол сервер талын хуудаслалт хэрэгтэй.
5. **Оюутны нэр засварлах** — нэрийн зөрчил илэрсэн үед админ интерфэйсээс
   засах боломж хараахан байхгүй, зөвхөн тэмдэглэгддэг.
6. **Нэг оюутан нэг тест** — схемийн `UNIQUE (test_id, student_id)`-ээр
   давхар өгөх боломжгүй. Дахин өгүүлэх шаардлагатай бол багш оролдлогыг
   өгөгдлийн сангаас гараар устгах хэрэгтэй.
7. **Файлын хэмжээ** — хүсэлтийн дээд хэмжээ 2 MB.
8. **Нэг үйлдлийн систем дээр нэг процесс** — SQLite нь зэрэг олон бичилтэд
   тохиромж багатай. Олон багш зэрэг ашиглах бол PostgreSQL руу шилжихийг
   зөвлөнө (`database.py`-д шилжилтийн заавар бичсэн).

## Supabase ашигладаггүй тухай

Энэ төсөл нь өмнөх React + Supabase хувилбарын **дизайн, layout, өнгөний
шийдлийг лавлагаа** болгон ашигласан боловч Supabase-ийн ямар ч код,
API, түлхүүр, хамаарал агуулаагүй.

Шалгасан зүйлс (бүгд **олдоогүй**): `SUPABASE_URL`, `SUPABASE_KEY`,
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `supabase-js`,
`supabase.from(...)`, `supabase.auth`, `supabase.channel`, Supabase руу
чиглэсэн `fetch` дуудлага.

Мөн `.env` файл, API түлхүүр, token, хувийн credential энэ багцад
агуулагдаагүй. Өгөгдлийн сан дахь мэдээлэл нь бүхэлдээ синтетик демо өгөгдөл.
